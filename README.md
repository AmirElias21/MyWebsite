# MyWebsite - Birthday Invitation

A small HTML practice exercise: a birthday invitation page with a cake image, a list of things to bring, and a Google Maps link.

## View locally

Download or clone the repository, then open `index.html` in a browser. Keep `Birthday-Cake.png` in the same folder so the image loads. No package installation, build step, or server is needed.

## Files and scope

- `index.html`: invitation text, headings, ordered list, image, and map link.
- `Birthday-Cake.png`: the cake image used on the page.

This is a static exercise, with no RSVP form, backend, or saved guest information. The map link opens an external site. The repository also contains a GitHub Pages workflow for publishing the static page.
